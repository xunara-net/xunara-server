# ADR-0026：密码登录会话与成功审计原子提交

- 日期：2026-10-11
- 状态：Accepted
- 范围：本地密码登录成功路径；不更改身份模型或官方客户端协议
- 提案：[密码登录原子审计](../proposals/atomic-password-login-audit.md)

## 背景

JSON 和兼容 HTML 的密码登录已经共用业务入口，但会话先提交，控制层随后
尽力记录成功日志。真实审计故障仍返回 200；忽略会话插入时也返回不存在的凭据。
这不满足关键身份操作可审计及持久提交后才签发凭据的要求。

## 决策

CreateLocalSession 沿用既有密码复核事务，在同一提交点持久化会话与两项必需
成功事件。复用严格检查单行写入的 Identity 审计助手，createSession 也验证
插入行数。失败或取消返回空会话/凭据，旧会话保持。控制层删除重复成功日志。
事件不存登录名、密码、密码 hash、token 或 token hash。

## 影响与边界

无新迁移或 HTTP 字段，不修改 wire、Entitlement、ACL、地址或 Headscale 依赖。
CreateLocalSession 成功必需两项审计，存储故障失败关闭。通用 CreateSession
不声称完成密码认证；测试预置会话与真实登录分别验证，不能删成功事件以凑计数。

失败审计可靠投递、其他认证方法整体事务、IP/User-Agent 及完整登录历史页面
仍待后续任务。累计 DNS v24 升级必须保留逐租户只读预检和维护一致性备份。

## 验收

覆盖两项审计各自的 ABORT/IGNORE、会话 IGNORE、恢复、取消、旧密码拒绝、
跨连接并发成功事件配对及 JSON/HTML 单次审计、503/旧 Cookie 保留。
完整回归和上线事实单独记录，不以本 ADR 推导生产已升级。
