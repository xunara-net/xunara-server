# ADR-0016：密码登录共用业务路径与失败关闭

- 状态：Accepted
- 日期：2026-10-09
- 延续：[ADR-0012](ADR-0012-authentication-storage-failures.md)
- Proposal：[密码登录故障收敛](../proposals/2026-10-09-password-login-failure-consolidation.md)

## 背景

正式 API 和兼容 HTML 密码登录重复实现业务，两处限流存储故障仍继续验证；身份
布尔读取隐藏存储错误，密码登录的初始化计数可能把故障解释为需要重新初始化。
实际 SQLite 故障用例分别复现放行 200、错误密码 401、未初始化 409 和存储失败
500，而不是统一的认证不可用。不能靠不用旧页面来保证没有认证旁路。

## 决策

- 两种入口只保留载荷解析、HTML CSRF、响应格式与回跳差异，共用持久限流、
  身份/凭据查询、bcrypt 校验、事务型本地会话创建和既有审计调用。
- 登录名、凭据及初始化数量读取带请求 context，保留存储/扫描/取消错误链。
  原布尔及数量读取仅薄适配同一 SQL，供仍需渐进迁移的调用方使用。
- 认证故障返回脱敏 503、重试提示和禁止缓存，不签发或清理 Cookie、不跳转
  初始化。确认未知用户、无本地密码、错误密码与验证后被并发改密仍统一 401。
- 原 IP 与登录名预算、大小写规则、真实 bcrypt 成本、Cookie 及成功载荷保持，
  切换新旧入口不能获得额外预算；慢校验后仍在事务内复核已验证密码哈希。
- 数据库结构、迁移、套餐、外部提供方准入、机器身份及客户端协议不变。

## 验收

真实 SQLite 的限流插入/更新、用户/凭据读取和会话写入故障必须失败关闭。
恢复后原会话保留，新旧密码入口恢复正常；不泄露测试密码、会话令牌或数据库
诊断。补共享预算、进入共用路径前已取消请求的零写入、读取无记录/扫描失败/关闭数据库测试，
并执行定向重复、全量 build/vet/test/race、CI 与发布产物浏览器回归。
本地完整验证通过后接受本 ADR；部署还必须等待对应提交的 CI 与发布产物浏览器
回归通过，不用定向结果替代全量结果。

上述本地验证已通过：身份查询与密码故障/恢复专项 race 重复 20 次，共享预算
race 重复 5 次；build、vet、全量普通测试和全量竞态测试通过。前端产物未改，
用户 Web 92 项与超管 25 项测试及生产构建重新通过。对应提交的 CI、发布二进制
浏览器回归与公网只读验收在部署记录中单独确认，不沿用上一版本结果。

## 尚缺事项

成功登录审计仍在会话提交后执行，尚未与会话原子绑定。启动初始化、其他旧
只读/写入口、第三方首次建号、完整恢复与多实例仍需继续逐调用点审查；
此决策不代表这些边界或全规格已经完成。
