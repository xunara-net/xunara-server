# ADR-0020：中继期望配置的版本保护与事务历史

- 状态：Accepted
- 日期：2026-10-10
- 提案：[配置保护与历史恢复](../proposals/2026-10-10-relay-configuration-history.md)

## 决策

用户中心与平台后台共享同一中继版本链。修改要求当前配置版本，删除要求版本
前置条件；缺失 428、冲突 409。不能为旧操作者自动读取当前版本再覆盖，否则
仍会绕过并发保护。旧页面和自动化调用必须升级；不宣称这是操作 API 的零变更。

当前配置仍以 `relays` 为权威，不新增重复配置头。历史复用本租户既有历史表，键为
`relay:<id>`；首次修改采集原始快照，之后不可覆盖已存在版本。查询最近 50 项，
恢复作为新版本提交。历史包含状态、带宽和地区显示名，不包含服务身份或遥测。
损坏/不完整历史失败关闭，不补缺省值后伪装恢复成功。

网络写事务复核持久会话/API Key 与管理员角色；API Key 范围读取沿用既有逗号分隔
持久格式，拒绝未知范围，不另创 JSON 格式。平台入口仍只接受独立平台凭据，按
解析到的租户选择存储并记录平台来源。配置、历史、审计与通知版本同事务提交。

删除同事务撤销服务身份、清理历史和写入审计。撤销是服务身份终态；恢复旧配置
不能重新启用已撤销凭据，重新接入必须签发新的服务身份。两个 Web 保留冲突草稿，
展示最新配置并要求显式确认新基准，再由操作方手动提交。

## 兼容与后续

无数据库迁移，state v21、identity v13 不变；不改官方 DERP/STUN、Noise、DNS 或
Relay 心跳字段与 opaque 配置版本语义。现存用户、会话、设备、凭据、TLS pin、
静态地图与 Entitlement 保持不变。平台读故障返回 503，不能伪装成空中继列表。

期望配置与已执行事实分离：当前 Relay 心跳回调仍只记录收到的配置，不宣称远程
限速、断开既有连接或运行时状态应用已经完成。地图移除与新的准入拒绝也不代表
既有连接立即断开。真实执行、执行回执、跨租户公共发布与升级仍是后续切片。

验证包括两连接 CAS、身份撤销/降权、损坏历史、事务故障回滚、取消请求、租户边界，
以及用户/平台浏览器的冲突确认、恢复与长历史滚动。具体接口与验证命令见
[网络控制台说明](../network-console.md)。
