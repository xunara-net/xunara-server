# ADR-0046 删除账户后允许重新注册

- 状态：Accepted
- 日期：2026-10-14

## 决策

已完成的公开用户名只在原账户仍有效时占用。平台删除独立租户时，先退出服务、
关闭旧数据库并归档状态，随后在一个注册表事务中删除组织和对应用户名占用。
内部失败回滚保留原有独立清理规则，不因普通注册表删除而释放已完成账户。

升级启动时仅清理组织已不存在、非配置组织、且原状态目录不存在的历史占用。
任何读取、归档、关闭或事务失败都不释放用户名。重新注册建立全新状态和 Noise
密钥；旧会话、Auth Key、设备范围绑定和审核记录不继承。原生路由保留旧绑定的
控制面公钥代际，不能因为组织短名复用而重新获得信任。

## 验证

覆盖删除后同名重注册、大小写重复拒绝、旧状态不继承、原生绑定代际不继承、
删除事务回滚、升级清理，以及仍有效账户和残留状态目录的保留。
