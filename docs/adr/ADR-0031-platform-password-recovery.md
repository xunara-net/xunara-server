# ADR-0031：平台辅助的密码重置与匿名兑换

- 日期：2026-10-11
- 状态：Accepted
- Proposal：[平台辅助密码恢复](../proposals/platform-password-recovery.md)

## 决策

新增独立持久重置凭证，不复用 Session、OAuth State、设备授权或内存 map。
仅已验证的平台授权可生成，必须携带账号版本和核实原因；仅有效凭证可兑换。
生成不改变密码或登录，兑换后替换密码、撤销人类会话、消耗码与审计原子提交。
一码、单用户、单租户、短有效期、仅哈希落库；旧凭据变化与账号状态变更使码失效。

匿名恢复表单不按邮箱定位账号，不自动开 Session；平台响应只展示一次秘密，
后续查询只有状态 / 期限。结果未知不能自动生成第二个码，也不能重放密码写入。
平台继续使用现有部署 Bearer，独立超管身份 / MFA、邮件验证和自动邮件恢复另行设计。

## 兼容与后果

Identity v17 只追加表；旧账号、密码、会话与机器默认不变，state/plans 不变。
安全升级需停止全部旧控制面并成套备份 / 恢复，不能混版本滚动运行。
密码恢复不是取消外部绑定或冻结网络，未验证邮箱仍只是联系属性。
人工渠道核实归平台运营者负责；没有真实邮件通知时不声明完整自助找回已完成。
