# ADR-0017：本地 owner 的一次性原子初始化

- 状态：Accepted
- 日期：2026-10-09
- Proposal：[初始化与自助租户 owner 的原子认领](../proposals/2026-10-09-atomic-owner-bootstrap.md)
- 延续：[ADR-0007](ADR-0007-self-service-tenancy.md)、[ADR-0012](ADR-0012-authentication-storage-failures.md)、[ADR-0016](ADR-0016-password-login-consolidation.md)

## 决策

初始化与自助注册必须认领同一个内置 owner，而不是创建第二个用户。认领是只能
成功一次的账户开通，不是密码重置：持久完成事实、用户资料、本地凭据、会话及
成功审计由同一个租户身份事务提交。慢哈希在事务外完成，事务内先获取一次性
名额，再读取及更新内置 owner，任何故障整体回滚，不向调用方返回部分身份。

追加身份迁移 v13 保存完成事实，并回填现有本地凭据或明确的完成审计。删除密码、
丢失或残留文件令牌均不能重新开放已完成的初始化。保留用户 ID、创建时间、所有
既有 `(provider_id, subject)` 链接和机器归属；邮件仍只是属性。

启动和 HTTP 初始化状态使用同一带 context 的错误查询。数据库或文件证明读取
失败不等于尚未初始化或错误令牌；持久限流失败不能继续开通。正常端点、成功
载荷、Cookie、注册策略、Free 10 设备与一名成员不变，不改变任何官方客户端协议。

## 迁移与恢复

不改已发布迁移或既有业务数据。旧版本拒绝较新的身份 schema，所以跨版本回退
必须恢复升级前一致性状态，并在恢复公网写流量前完成；只替换旧二进制不是有效
回滚。已恢复公网业务后的数据库禁止直接用旧快照覆盖。

## 验证与边界

按 Proposal 完成真实存储故障、并发、迁移、重复与重启回归，以及全量竞态和
发布产物浏览器验收后接受本 ADR。平台组织 / 套餐跨库补偿、初始占位用户播种、
其他成功登录和第三方建号的原子性不在本决策已完成范围内。

本地 build、vet、全量 test / race 通过；初始化、owner、失败开通和迁移专项 race
重复 20 次通过。测试先复现限流故障仍成功、元数据假判断和半初始化；随后覆盖
全部身份写点 / 最后审计失败回滚、两个连接 / 实例竞争、删除密码与残留令牌、
重启、损坏 / 非 `0600` / 链接证明、取消及恢复。旧 v1 迁移夹具改用真实已发布
DDL，而不是缺少审计表的简化模型；未修改任何已发布迁移。

Web 106 项、Admin 25 项和生产构建通过，隔离浏览器 25 阶段通过、JS 错误为零。
真实旧版本隔离状态进一步验证 v12 → v13 保留身份、密码及会话，以及同时恢复
旧产物 / 一致性状态后旧版本仍可登录。对应提交 CI、最终发布产物与调试部署
必须在部署记录另行确认，不把本地夹具作为生产回退或公网 OIDC / 数据面证据。

SQLite 事务行为核对使用项目固定版本的 `modernc.org/sqlite` 源码及
[事务控制](https://www.sqlite.org/lang_transaction.html)、
[连接隔离](https://www.sqlite.org/isolation.html)官方说明，不依赖进程内锁防止跨实例认领。
