# ADR-0033：本人账户安全资料的有界导出

状态：接受。Proposal 见[本人账户安全资料导出](../proposals/account-security-export.md)。

## 决策

本人 JSON 安全资料与 CSV 成功登录记录由单个租户身份事务准备，而不是拼接
多个页面 API 或开放数据库备份。当前有效 Human Session 在事务内再次核实，
成功快照与必需准备审计同事务提交；HTTP 同时要求 CSRF 与持久有界限流。

明确白名单投影、半开时间区间、每集合 5000 行及文件 8 MiB 上限；超限不返回
截断文件。范围不涵盖完整租户配置、其他用户、凭据和原始机器 / 服务身份。
准备审计仅说明快照生成，不声明客户端落盘。编码完毕后作为 no-store 附件
响应，浏览器显式确认下载并清理 Blob，服务器不保存公开导出资源。

CSV 是供人查看的文本表格，对危险公式文本添加可见前缀；JSON 是不改变
显示值的机器可读格式。历史时间筛选不隐式删除旧数据或筛选账号资料 / 绑定。

## 影响

不新增迁移或变更现有 API / 套餐 / Tailscale wire。仅追加本人导出接口与审计
动作；权限不以平台令牌或网络管理员身份扩大。事务会短暂取得身份库写锁，
有界行数、请求 context 与限流控制代价，不声称异步无限规模导出已实现。

使用、实际验证与局限以[服务端手册](../account-security-export.md)为准。
