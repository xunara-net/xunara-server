# ADR-0047：账户定向设备分享与生命周期隔离

状态：Accepted（2026-10-15）

## 问题与决策

已有分享只接受外部 `(provider_id, subject)`，普通密码账户无法使用。分享还只保存租户名和数字节点 ID，删除租户后重建可能错误继承旧关系。用户中心改为输入接收人的登录名，由平台唯一解析到现存人类账户；不存在、重名、禁用账户统一拒绝，不提供账户目录搜索。

新增独立 `account` 目标类型，持久绑定目标租户实例、公有 Noise 身份、用户 ID 和用户创建时间，不把本地用户名或邮箱伪装成外部身份。来源也绑定租户实例、节点 stable ID、创建者及其创建时间。改名不改变关系；删除重建、节点替换、禁用任一参与者均不能继承访问。Noise 身份更换后必须重新分享。

只分享选定机器，不分享整个网络、子网路由、出口、设备管理权限或安全凭据。接收人必须使用有效人类会话明确接受；Service Key 不能接受账户分享。创建/接收/拒绝/撤销均要求 CSRF，数据库写锁内复核会话和创建方管理角色。双方均能撤销；接收方其他成员看不到邀请或机器。

## 存储与失败处理

在 shares.db 追加 v2，不修改已发布 v1。新建与状态转移和平台分享事件在同一事务提交；事件写失败必须回滚。租户身份库的锁在平台事务提交前持有，防止旧会话/降权快照继续写入。租户普通审计用于展示，不宣称跨库原子提交。

旧 v1 活跃关系没有实例边界，升级时保留历史但撤销访问，需重新发出分享；不得推测当前同名租户就是原租户。平台迁移的 DDL 与 user_version 原子提交。数据库错误不是成功空列表或未知账户。

## 官方客户端兼容

沿用锁定的 tailscale.com v1.104.0 `Node.Key/Machine/DiscoKey` 和 `SelfNodeV4/V6MasqAddrForThisPeer`，不新增协议字段。修复共享投影漏传公开密钥。共享地址使用已有双向 masquerade 分配，原地址不跨租户。Tailnet Lock 暂不支持跨网签名，明确拒绝分享。

参照 [官方分享与 quarantine](https://tailscale.com/docs/features/sharing)，接收方允许自己发起连接，共享机器只能回复，不能凭默认 allow-all 主动进入接收方。通过上游有状态包过滤语义限制共享来源；互相分享可各自授权发起。双方 ACL 仍然生效，不自动改写用户策略。公开密钥用于协议连接，不是人类或机器自动授权。

## 验证

覆盖本地账户完整生命周期、CSRF/Service Key/角色、同名与删除重建边界、并发状态竞争、迁移/必需事件回滚、公开密钥/masquerade/ACL/quarantine/MagicDNS/撤销 netmap。前端覆盖响应校验、未知结果手动刷新、手机弹窗/分享收件箱与实际后端浏览器流程。
