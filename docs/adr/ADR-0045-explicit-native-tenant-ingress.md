# ADR-0045 统一账户登录与共享原生设备接入

- 状态：Accepted
- 日期：2026-10-14
- 提案：[接入与核心一致性](../proposals/2026-10-14-core-admission-consistency.md)

## 决策

新增可选 self_service.native_gateway，必须配合共享控制台的规范 origin 和组织
注册表。默认关闭，原单租户/独立 Host 模式不变。开启后共享入口仍使用原 Noise
密钥及标准客户端根地址，不向官方客户端增加自定义协议字段或控制路径。

未知设备取得独立持久接入流程，只保存精确 MachineKey/NodeKey、注册元数据与
期限。浏览器通过普通账号登录确认接入账户，不要求用户填写网络标识或选择
登录范围；入口站管理员 Cookie 不自动选择目标、不批准机器。随后跳到目标
租户自己的授权页，由其会话/CSRF/原子审批确认授权。入口密码登录按所有有效
账户的唯一登录名定位；历史同名账户失败关闭，不按密码、邮箱或默认租户猜归属。

组织注册表只追加 v3：持久机器/节点对的路由绑定和独立原生接入流程。绑定还
记录目标控制面的持久 Noise 公钥，防止删除后复用组织 ID 继承旧路由。路由绑定
不是机器信任；Map 和辅助端点仍验证目标租户自己的节点与机器键。已授权节点
升级时仅补录自己的范围，不转移用户、设备、地址或密钥。

所有 Noise 内层端点使用不可变的逐请求范围。NodeKey 请求正文与 LB 提示必须
一致；提示本身不授予身份。缺键辅助请求只有机器明确属于单个有效范围才路由；
歧义、失效组织、存储故障失败关闭。无效/跨范围 Auth Key 不回退到浏览器或默认
管理员。旧入口未选择范围的待审批申请拒绝通过旧书签继续放行。

无签名的新节点键重新登录仍需要普通账户确认，不因 OldNodeKey 提示回到默认
管理员；已签名的静默轮换只路由原租户，签名有效性仍由其 Core 检查。

浏览器路径只追加设备/SSH 授权页面及其决定；Cookie 始终按自己的租户名/路径
转换，普通网页 API 与客户端入口元数据分离。开启模式时显示规范原生入口和明确
账户确认，不根据浏览器地址猜 login-server。已有错误归属必须重新授权，不改库搬迁。

## 验证与升级

真实上游 TS2021 传输验证两个独立状态库、旧管理员 Cookie、普通账户登录、精确键、
Token、Map/DNS/ACL/DERP、辅助端点、重新连接与持久恢复，并运行完整 race。
复用已有正式证书和 Noise 密钥，完整停服备份后开启；不新旧版本混写 v3 注册表，
恢复写入后不得覆盖旧快照。仅本地传输验收不代替 Windows/Android 等设备现场验证。
