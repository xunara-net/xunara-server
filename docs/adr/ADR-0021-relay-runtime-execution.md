# ADR-0021：中继运行时执行与服务身份回执

- 状态：Accepted
- 日期：2026-10-10
- 提案：[中继运行时与回执](../proposals/2026-10-10-relay-runtime-execution.md)

## 决策

期望配置、实际应用、缓存持久化和服务端接收报告是独立事实。Relay 使用现有官方
DERP Handler 与准入，连接级双向限速热更时取消旧等待并完整分段计费。维护拒新
连接但保留既有连接；停用/撤销断开现有 TCP 并拒绝新的 DERP，恢复启用无需重启。

新托管进程在确认控制面授权前不开放 DERP。缓存绑定服务身份，只用于版本高水位/
撤销保护，不凭缓存重新授权；运行中控制面故障保留当前配置和已建立连接，未知
客户端准入仍失败关闭。同序号异配置与倒序拒绝，应用/持久化失败可以重试。

增加可选配置序号及心跳执行报告，既有 opaque token 不改等值语义。旧 Xunara
规范十进制 token 可作为兼容序号，无法确定序号不猜顺序。回执记录固定错误码，
不记录秘密/原始服务端错误；报告与业务用户/设备身份隔离。

state v22 只追加报告及服务端时间；心跳事务按服务 token hash 解析并复核本租户
身份/撤销、版本和字段，遥测/回执事实变化审计同事务提交。旧 Relay 省略报告仍
可用，但执行状态未知，不能沿用旧回执假称新进程已执行；失联报告也不是实时证明。

## 兼容与风险

不改官方客户端 wire、套餐、Headscale 或静态公共 Relay 的配置/TLS pin。回执是
服务身份自报，不替代官方客户端真实转发/限速与 TLS 验收。地区显示名更新不改变
地区编号、端口、证书或节点密钥。停用会断开连接，必须在两个后台明确提示。

先升级服务端，旧二进制拒绝 v22。恢复公网流量后不能再覆盖旧状态；隔离快照演练
不代表生产回退或全平台灾备完成。跨租户公共发布、成本计费、签名升级与全 OS
数据面矩阵仍是独立后续工作。
