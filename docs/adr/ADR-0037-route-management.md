# ADR-0037：路由与出口审批的事务闭环

状态：接受（2026-10-12）。Proposal 见[提案](../proposals/2026-10-12-route-management.md)；
任务 [Server #18](https://github.com/xunara-net/xunara-server/issues/18)。

## 决策

路由页和设备详情共享审批差量、预览确认及最新状态恢复。路由不是 ACL，出口
选择永远客户端本地；匹配、自报或在线不能当成真实数据面证明。

新管理 API 强制绑定身份/归属/宣告/批准的摘要版本，仅允许批准当前宣告；
持久凭据/角色复查、路由差量、必需审计和配置通知同事务，读写有界，
无变化不新建审计/通知，存储错误失败可见。v1/HTML 只作兼容适配。

出口与子网 Entitlement 独立，新增受门禁，降级可清理。Map 遥测保留当前
管理事实并核对机器/节点身份；流断开活动只更新时间字段。冲突/未知结果
不自动重试，采用最新基准只重放明确意图，再重新确认。

## 影响

无迁移、官方 wire 或选举/故障转移算法变化，不依赖 Headscale 内部表。
v1 Cookie 写入必须 CSRF，服务写入执行 API Entitlement；不远程切换出口，
不承诺实时路径或全平台现场可用。契约与测试见[路由手册](../route-management.md)。
