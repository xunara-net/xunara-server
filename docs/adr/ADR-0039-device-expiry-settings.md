# ADR-0039：单设备有效期管理

状态：接受（2026-10-13）。见[实施前提案](../proposals/2026-10-13-device-expiry-settings.md)。

设备管理沿用 ADR-0038 的持久管理员授权、身份/有效期 CAS 与原子审计通知，
添加定时过期、关闭过期及已过期设备固定 30 分钟临时恢复。旧立即过期接口
委托同一写路径；不混用整行旧快照更新。只有授权管理员可延长，机器注册
仍只能缩短既有有限有效期，不能绕过授权恢复已过期设备。

相对时间从服务器写事务内计算，指定时间最多未来 180 天；空 expiry 使用原有
SQL NULL / Tailscale 零时间。指定日期仅作用于当前节点密钥，不修改网络默认
认证周期或重新认证策略。有效期变化下发既有 KeyExpiry，官方客户端计时。

权限/租户、参数、事务回滚、跨连接竞争、重启读回及 Noise Map / 手机 UI
回归必须覆盖。发布不试写生产设备，不修改原证书、令牌或默认中继。

本地 Go build/vet/test 与全量 race 通过；Web 435/Admin 51 单测及类型/构建、
100 阶段真实 API/手机隔离浏览器通过，JS 错误零。Noise Map 验证有限/零/过期/
临时恢复有效期，客户端不能延长管理员窗口。跨连接读回不是整机灾备恢复
测试，Chromium 手机尺寸不是 Android/iOS 官方 APP 现场复测。
