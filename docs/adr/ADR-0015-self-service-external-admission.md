# ADR-0015：自助入口禁止第三方隐式加入共享网络

- 状态：Accepted
- 日期：2026-10-09
- 补充：ADR-0007、ADR-0014，不改其既有独立租户和外部身份键决策。
- 提案：[自助入口外部身份准入](../proposals/2026-10-09-self-service-external-admission.md)。

## 决策

首次外部登录不能在自助开通入口创建成员。未知 `(provider_id, subject)` 返回
`TENANT_SIGNUP_REQUIRED`，不创建账户、身份链接或会话；相同邮箱不能认领已有 owner。
在入口显式绑定的身份仍可登录，普通目标租户继续执行自己的提供方规则和成员额度。
检查放在所有外部身份结果共用的映射处，不只保护新的浏览器起始 API。

这是对既有“一账户一独立 tailnet”边界的失败关闭修复，不等于实现第三方自助开网。
未来支持该功能需独立处理全局身份、租户开通、额度/链接一致性及会话交接。
不改数据库迁移、套餐额度或官方客户端 wire 协议；不得把人类登录变成设备可信。
