# ADR-0049：完整退役内嵌用户控制台

- 日期：2026-10-16
- 状态：已接受，取代 ADR-0003 中“功能对等前保留旧控制台”的决定

> 本文曾保留的独立授权、初始化、错误页和语言样式辅助实现，现由
> [ADR-0050](ADR-0050-browser-ui-retirement.md) 全部退役。客户端浏览器 URL 仍保留，
> 但由独立 Web 提供界面，旧表单提交不再执行。

## What changed

- 删除内嵌用户中心的页面模板、导航、JavaScript 和全部表单处理器，不再编译一套备用中心。
- `/console` 与已知子页面仅迁移到新 Web 页面；未登录先到统一登录，已登录按租户跳转。
- 所有旧控制台写方法返回 `410 CONSOLE_RETIRED`，包括旧通行密钥别名；未知旧页面返回 404。
- `/console/ssh-check` 对应新安全中心的 SSH 审批记录，沿用既有只读 v2 API 与持久记录。
- 独立初始化、浏览器登录、设备批准及 SSH 批准页面继续存在；它们不是完整控制台。
  共用样式、本地化、时间与设备显示名提取为独立辅助文件，语言偏好改走 `/ui/prefs`。

## Why

线上用户看到的“Xunara console · vdd158e9”来自当前服务端，不是浏览器缓存，也不是旧
dist 文件：先前仅退役部分账户页面，旧 `/console/*` 路由和 nginx 反代仍真实运行。
继续保留完整旧中心会让新旧权限、操作路径和产品界面长期混用。

不再以新界面尚未覆盖全部非核心模块为理由保留第二套中心。Reach、Flux、服务和 Webhook
等现有 API / CLI 能力不删除；缺少新 Web 页面的部分仍是明确的产品缺口，不伪装成迁移完成。

## Compatibility impact

- 本变更仅处理人类浏览器管理界面，不修改 TS2021、Noise、Register、Map、DNS、DERP 或 SSH 协议。
- `/register/{id}`、`/ssh/check/{id}` 及对应带 CSRF 的批准 / 拒绝端点保留，不能按 `console` 一并封掉。
- 新 Web 的登录回跳会把旧书签规范化，不再完整导航回旧中心；旧查询参数不继续传播。
- nginx 的根与租户 `/console/*` 都只转交退役处理器，不回落到 SPA 或历史静态文件。
- 先部署同时包含新安全中心与旧回跳规范化的 Web，再部署服务端和代理规则。
  仅部署服务端的环境也需部署独立 Web；不再提供内嵌中心兜底。
- 无数据库迁移；不删除账户、设备、套餐、授权或中继数据。回滚只恢复二进制、Web 和代理配置。

## Security impact

- 旧表单不再执行，即使携带有效 owner 会话与 CSRF，也不能修改设备、账户或权限。
- 书签映射只采用固定目标与可信部署地址，不采用请求 Host、旧 query 或外部 return_to 决定目标。
- 租户路径继续使用独立 Cookie，未知租户不暴露中心；迁移不会把设备批准转移给入口管理员。
- SSH 记录不新增批准入口，不将“已批准 / 结果取走”描述为连接成功；失败不能伪装成空列表。
- 原有 JSON 会话兼容端点仍需 Human Session + CSRF，与已停用的旧 HTML 表单区分。

## Tests

- 服务端覆盖旧 GET / HEAD 迁移、未登录回跳、旧写入口 410、状态不变与路径租户隔离。
- 保留既有 API、官方客户端注册和 SSH 检查集成测试；只移除已删除 UI 的渲染 / 表单契约测试。
- Web 覆盖旧书签规范化、SSH 状态 / 游标 / 畸形数据 / 取消读取；浏览器覆盖窄屏记录与回跳。
- 真实 nginx 隔离回归确认退役路径到 Core 而非 SPA，设备 / SSH 浏览器授权与 TLS 不变。
- 执行 `go build ./...`、`go vet ./...`、`go test ./...`、`go test -race ./... -timeout=30m` 及 Web 测试和构建。
  整包包含大量真实密码哈希，竞态检查沿用 CI 的三十分钟包级预算，不以默认十分钟截断。
