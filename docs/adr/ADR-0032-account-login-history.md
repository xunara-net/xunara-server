# ADR-0032：登录历史与 Session 生命周期分离

- 日期：2026-10-11
- 状态：Accepted
- Proposal：[独立登录记录与最近活动](../proposals/account-login-history.md)

## 决策

追加独立成功登录记录，保留 Session 公共 ID、认证方法、初始来源与生命周期事实，
不持有任何 token / hash。创建和更新由身份库 AFTER 触发器原子记录，必须影响
预期行数；会话过期清理不删历史，删用户在同事务删除历史。旧会话回填明示旧记录，
没有来源的事实不猜测；轮换继承来源且独立标记，不冒充新登录。

所有人类认证显式传入规范化来源，已有身份事务保持；已验证会话使用 context
读取和持久单调分钟节流更新。最近活动不是滑动过期，也不是客户端在线证明。
只提供本人 Session 只读分页；服务 Key、机器和其他成员不得读取。

## 备选

- 继续用过期 Session：GC 丢失历史，拒绝。
- 每个撤销点手动复制记录：容易漏掉改密、恢复、停用、解绑、轮换和兼容入口，拒绝。
- IP / UA 绑定身份或外部定位：不可靠、增加隐私和出站依赖，拒绝。
- 单实例活动缓存：不能跨连接 / 重启，拒绝。

## 影响与后续

Identity v18 追加；state / plans、官方 Tailscale 协议与额度不变。原 token、时间
和权限不变；新旧控制面不得混用，回退恢复完整旧版本 / 状态。历史目前随账号保留，
未来需单独设计运营可控的保留 / 导出 / 删除策略；失败认证记录、地理定位、2FA
和完整多实例部署仍未完成。本切片不提供其他用户历史的管理员入口。
