# ADR-0030：平台账号禁用与启用 owner 不变量

- 日期：2026-10-11
- 状态：Accepted
- Proposal：[账号禁用](../proposals/account-suspension.md)

## 决策

禁用是租户内 Human Account 的持久状态，不是角色，也不是机器撤销。
状态编辑仅平台授权，使用用户 `updatedAt` CAS。禁用与浏览器会话撤销、必需审计
原子提交；所有签发入口检查启用状态，解禁只放开新登录，不复活旧会话。

最后 owner 保护统一计算启用账号，禁用 / 降权 / 删除使用同一数据库写事务边界。
API Key 的独立身份不变，但账号禁用期间不得借其委托角色获得 API 权限。
设备与中继身份、套餐额度和 TS2021 / Noise / Map 协议不变。

## 后果

追加 Identity v16，旧库升级不改变既有用户状态。旧二进制会拒绝较新 Identity
版本；回滚需在停止写入时使用同批次数据库与二进制快照，不能直接降版本。
账号禁用不是设备 / 网络停服；冻结网络、完整恢复和平台人身份另立工作流。
