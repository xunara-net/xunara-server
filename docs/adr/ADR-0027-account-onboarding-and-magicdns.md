# ADR-0027：显式 MagicDNS 初始化与账户级外部认证

状态：Accepted

依据：[Proposal](../proposals/account-onboarding-and-magicdns.md)。

用户端不能把未配置域名和缺少绑定流程包装成已完成。采用显式首次初始化、持久命名空间与不可变已绑定域；域名是内部解析后缀而不是公网或登录域名。基本设备名称解析属于基础网络能力，自定义 DNS 继续走套餐。

认证事务保留独立对象，只增加对人类用户/会话与邀请哈希的引用。绑定回调同时验证 OAuth browser binding 和发起会话，不复用设备审批。身份、邀请兑换、配额、会话和必需审计在同一个租户数据库事务内完成；不按 email 找用户。

closed/invite 不允许普通 OIDC 登录绕过准入，现有外部绑定不受此影响。邀请创建、密码兑换与 OIDC 兑换共享邀请对象，绝不把邀请码放在 URL 或浏览器持久存储。

没有真实提供方配置时，页面明确提示管理员配置而不生成虚假的“已绑定”。租户独立身份库保持不变，全球账户跨租户加入、邮箱发送与绑定域迁移不属于此决定。
