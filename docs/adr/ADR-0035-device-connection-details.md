# ADR-0035：设备连接报告与核心导航

状态：接受。Proposal 见[设备连接详情](../proposals/2026-10-12-device-connection-details.md)。

## 决策

租户设备只读 API 从持久 Node/NetInfo 与实际下发 DERP 快照投影白名单。
HomeDERP 是归属，不是任意 peer 的实时路径；检测报告没有独立检测时间，读取
时间不能冒充更新时间。保留 unknown/false，秒转毫秒，过滤坏测量与未下发区域。
输出有界，地图及来源共用不可变快照。Web 核心导航保留设备、网络、权限、DNS、
路由与中继，次要管理折叠但保留深链接/手机抽屉；失败和快速切换不混入旧设备。

## 影响

新增管理读取接口，不改官方 wire、身份、表结构或 Entitlement，不泄露原始
Hostinfo 或机器密钥，不跨租户查地图，不把在线/下发地图声称为真实网络可达。
契约、验证与局限见[核心设备与中继](../device-core.md)。
