# ADR-0019：本租户托管中继进入标准 DERPMap

- 状态：Accepted
- 日期：2026-10-10
- 提案：[托管中继自动下发](../proposals/2026-10-10-managed-relay-map.md)

新增可验证地区与证书信息，追加 v21。健康的本租户私有中继与静态地图合并，
旧记录不推断 pin/地区；DERPPolicy 继续限制下发，禁止覆盖静态地区、禁止投影
其他租户记录。用标准 DERPMap 增量更新，故障保留有效快照，不关闭 TLS 验证。
Relay 从持久服务身份确定租户准入 URL。TLS pin 轮换需后续受控流程，历史缺少
地区信息的 Relay 需升级后重新接入。心跳、地图/成本/升级不宣称是真实连接遥测。
