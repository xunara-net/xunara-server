# ADR-0043：公开开户名称唯一与用户默认网段

- 日期：2026-10-14
- 状态：Accepted
- Proposal：[用户名与默认网段](../proposals/2026-10-14-signup-uniqueness-and-default-network.md)
- 补充：ADR-0007 的公开开户名称约束、ADR-0041 的默认池选择；不改写历史决策。

## 决策

公开开户用户名全平台大小写不敏感唯一，组织短名不是唯一性的替代品。
组织表新增 v2 名称占用表；组织创建与名称占用同库同事务提交。
同名注册明确 409，不创建随机后缀的副本网络。
不同用户名映射到相同组织短名时仍可使用随机组织后缀。

启动前补齐现有有效用户名占用。旧同名用户、密码、独立网络与会话原样保留；
只阻止新增重复，不自行合并或选择登录归属。占用表不承担认证，不改变
租户内的身份键，也不按邮箱建立全局人类身份。

开户完成后保留名称墓碑；普通组织删除不回收名称。初始化未提交且组织已经
退出、套餐已清理时才能释放本次未完成占用。身份提交结果不确定时读取持久
完成事实；已经提交或无法确认时保留账户与占用，明确提示先登录核对，不自动
删除可能已生效的账户。失败清理使用独立有界上下文。

用户默认设备池继续由既有地址管理接口控制。附加池提供「设为默认网段」，
将旧默认池保留为附加池，预览、显式确认、版本及事务门禁不变。
新设备从新默认池分配，旧设备地址、ACL、DNS 与子网路由不隐式修改。

按运营者本次明确要求，调试部署在套餐目录为 Free 开启 AllowCustomCIDR，
不是绕过 Entitlement。内置 Free 默认和其它部署策略不变；10 台设备上限不变。

## 兼容与运维

只追加组织注册表 v2；Identity / State / Plans 无新迁移。
TS2021 / Noise / Register / Map wire 与机器、服务、中继身份不变。
升级应停止所有旧实例并私有备份；较旧程序拒绝读取注册表 v2，不能混版读写。
已经恢复公开写入后不得用旧快照覆盖新数据。

本决策不交付共享原生控制面，不把单域证书误称为租户泛域名证书。
既有独立客户端 URL 的 DNS/TLS 缺口仍需单独解决。
使用方式和恢复边界见[操作说明](../signup-network-settings.md)。
