# ADR-0005：租户网段由 Network Allocation Service 分配

- 状态：Accepted
- 日期：2026-10-09

## 背景

Free 用户不允许修改网段，付费用户可以自定义网段。网段必须避免与保留地址
（回环、链路本地、组播、文档地址等）、平台网络以及其它租户冲突。

## 决策

- `netspace` 包负责：CIDR 校验、保留段检查、冲突检测、地址池分配；
- 默认池 `100.100.0.0/16`，每租户默认 `/24`，可通过 `-network-pool` 配置；
- 分配结果写入租户记录，并下推到控制面的地址前缀；
- 自定义网段必须通过同一套校验，且不与任何已分配网段重叠；
- 免费套餐的网络地址由系统分配，用户不可修改（通过能力开关表达）。

## 影响

- 网段变更必须在控制面重启或节点重新注册后完全生效（地址前缀随分配下发）。
- 平台后台（xunara-admin）通过 `/api/platform/v1/organizations/{id}/plan/allocate`
  与 PATCH 接口管理分配。
