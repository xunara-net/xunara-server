# ADR-0023：合法 IPv4 自定义范围与官方兼容范围分离

- 状态：Accepted
- 日期：2026-10-10
- 提案：[放开自定义 IPv4 分配范围](../proposals/2026-10-10-flexible-ipv4-allocation.md)
- Supersedes：ADR-0022 的 CGNAT-only 分配限制；其余地址与中继决策保持

## 决策

按用户「不要限制网段」要求，合法 IPv4 分配范围不再局限于 CGNAT 或 /16～/28。
私有和公网单播范围经过保留/冲突检查后可保存；/31 与 /32 是小型主机池，
不能因套餐设备额度较大就禁止使用，也不能在地址耗尽时回退或重复分配。

「服务器允许配置」与「官方客户端保证兼容」分开表达。默认保留 CGNAT；
非标准范围显示风险，不修改客户端或兼容 wire 来伪造全平台支持。IPv6 仍由系统
分配。普通设备池保留网络/广播保护，/31 与 /32 使用其全部主机地址。

安全保护、套餐能力、写入身份、审计、持久版本、旧地址/历史网段预留与重启收敛
不变，不自动迁移任何生产网段。自动块搜索保留资源上限但不限制自定义池长度。

## 兼容性与恢复

无迁移或 API 字段变更，原标准网段仍有效。非标准地址的 LAN 冲突、IP 分类、
MagicDNS/路由/客户端功能风险需实测；本切片不承诺所有 OS 兼容。旧版编辑器
拒绝新开放范围，回退须保留当前状态并审查，不能在线恢复旧数据库快照。
