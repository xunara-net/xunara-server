# ADR-0041：主域名租户控制台、多 IPv4 池与接入冲突保护

- 状态：Accepted
- 日期：2026-10-13
- 提案：[共享控制台与网络安全](../proposals/2026-10-13-shared-console-and-network-safety.md)

## 决策

独立网络的浏览器入口与官方客户端控制面地址分离。可选共享控制台模式使用
入口规范 origin 下的组织路径，仍按独立状态库、会话、成员身份和权限授权。
组织 ID 不是认证凭据；Cookie 改用租户专属名字、host-only 和路径范围。
入口登录显式选择网络，不遍历所有租户根据用户名或邮箱猜账户归属。
新托管租户共用 RP 时，WebAuthn user handle 使用组织 namespace；
不修改入口站与平台管理员的凭据或已发布的默认 handle。

网页路径只承载 v1/v2 产品 API 与身份回调；不代理 TS2021、Noise、平台 API
或公共中继准入。旧组织 URL、Noise 密钥、数据库和主机路由不变。
共享网页解决不了独立客户端主机的 DNS/TLS：该入口仍需正式泛解析与受信证书。

设备 IPv4 管理增加多个附加地址池，默认池继续负责自动注册分配；
设备详情允许显式把单台设备改入任一池。修改/删除池不自动重编号旧设备。
全部池共用版本、entitlement、安全保留校验、跨租户预留、原子审计和收敛链路。
降级清除附加池的后续分配资格，但保留历史预留，防止旧设备 IP 被另一租户占用。
这是三层地址管理，不是 VLAN；权限只经现有 ACL/Grants 编译器明确控制。

客户端内部 Quad100 地址不可经控制面 DNSConfig 改写。Linux 接入命令默认先
进行只读网络检查：本地接口/显式路由与当前 IPv4 池或 IPv4/IPv6 Quad100 重叠时，
停止后续安装/接入；读取失败也停止，不静默修改本机 DNS 或路由。
关闭 `accept-dns` 不能承诺消除 Quad100 接管。未配置本地路由的外部服务冲突、
其他操作系统的自动检查和客户端自动改变虚拟 DNS IP 不属于本次已交付能力。

## 兼容与迁移

State v25、Plans v5 只追加默认值为空数组的字段。Identity 无新增迁移。
升级必须停止旧实例，备份完整数据库、配置和程序后先发布 Server 再发布 Web/nginx。
已恢复公开写入后不允许直接用旧数据库快照覆盖新数据。

## 验证边界

Go 回归覆盖多池、旧地址保持、跨租户预留、套餐降级、实际密码再次登录、
Cookie 隔离与标准 MapResponse 的地址/单主机 AllowedIPs 投影。
浏览器验收使用仅入口主机的测试证书与 DNS 映射，租户主机故意不可解析，
不能靠通配证书或泛 DNS 掩盖注册跳转故障。虚拟认证器验收不代替手机实机验收。
