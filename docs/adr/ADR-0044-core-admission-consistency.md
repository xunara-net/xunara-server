# ADR-0044 核心授权 策略与迁移一致性

- 状态：Accepted
- 日期：2026-10-14
- 提案：[核心接入一致性](../proposals/2026-10-14-core-admission-consistency.md)

## 决策

设备审批与节点授权是同一数据库提交边界，不以进程本地锁保证跨实例正确性。
发起会话/服务凭据、角色、精确键、待审批事实、额度、节点创建/合法轮换、决定、
必需审计与通知版本都在事务内复核。失败不产生已授权节点，重复决定不得改归属。
人类 Session、服务 API Key 与私有内嵌管理入口保持区分，不通过身份互推信任。

策略文件与数据库发布使用同一严格解析器；未知限制条件拒绝而非忽略。
应用 Grants 的通配地址保留标准地址范围，只追加实际租户节点的非标准单主机地址，
覆盖附加池和保留的旧地址，不放宽到整个外部网络或其他租户。

组织/套餐注册表的单次迁移与版本记录同事务，并在写锁内读取版本。已发布 SQL
永不修改；已存在的部分迁移异常仍拒绝启动，不自行删列或猜测版本。

## 影响与验证

不改变官方客户端 wire 类型、Noise 密钥、地址或设备身份。本切片无新增迁移；
原合法策略保持兼容，过去被忽略的未知字段现在必须显式修正。需审批故障回滚、
跨连接竞争、严格策略来源对等、实际地址 CapGrant 与中断/并发迁移回归，以及
完整 build/vet/test/race。共享原生接入另按提案完成独立路由设计与协议验收。
