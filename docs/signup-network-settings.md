# 公开开户用户名与默认设备网段

## 名称唯一

入口站公开开户使用全平台唯一、大小写不敏感的用户名。前后空格不形成新用户；
其余非法字符、超长及会被过滤改变的用户名直接拒绝，不静默改名。
重复开户返回 `409 LOGIN_NAME_TAKEN`，不创建第二个网络、套餐、地址分配或会话。
IP 限流仍生效，大量重复请求可能先被 429 拦截。

组织 ID 由用户名生成；不同合法用户名的短名转换结果可能相同，此时仍可为
组织追加随机后缀。这个规则不能用于同名账户重复开户。
邮箱只是属性，不据此合并账户；共享入口用普通登录名和密码自动定位独立账户。
登录页不要求选择登录范围或填写网络标识，历史同名账户失败关闭，不猜测归属。

升级发现旧重复账户时只补齐名称占用，保留全部账户和独立网络。管理员应与
用户核对实际使用的网络再安排迁移或删除，不能只按名字删除副本。
正常删除网络先关闭并归档旧状态、清理套餐，再同时释放组织和用户名占用。
同名重注册创建全新账户，不继承旧会话、设备、密钥或套餐。升级仅清理组织已
不存在且原状态目录也不存在的历史占用；残留状态和仍有效账户不自动释放。

开户初始化失败只在确认未产生 owner、组织退出且套餐已清理后释放未完成占用。
提交 / 断连结果不确定时显示 `REGISTRATION_OUTCOME_UNKNOWN`，先使用刚设置的
登录名和密码尝试登录，不自动重复开户或清空可能已经成立的账户。
长期未完成的开通需要运营者检查状态与归档后人工恢复，没有自动超时回收。
未完成占用同时保留组织 ID，另一数据库连接也不能在组织退出、套餐清理尚未完成
的窗口复用该 ID；失败的冲突请求不会替原请求释放名称。只有实际提交了组织的
构造失败路径才能执行自己的补偿。

## 用户默认网段

网络 owner/admin 在用户中心「我的网络 → 修改分配网段」设置默认 IPv4 CIDR。
已有附加网段可点击「设为默认网段」，原默认池自动放回附加列表。
先校验与预览，再确认保存；取消不写入。旧版本、权限变化、冲突或尚未应用的
配置拒绝覆盖，不能通过刷新自动重试写操作。

新设备使用当前默认网段；已有设备的 IP 不自动改变。需要移动设备时到设备详情
逐台修改 IPv4，并同步按 IP 编写的 ACL、应用及外部 DNS。池本身不是二层 VLAN，
也不自动授予跨池访问权限。

默认池及附加池都受持久套餐的 `AllowCustomCIDR`、网络角色、CSRF / write scope
及合法 / 保留 / 跨租户冲突检查约束。平台管理员可在「套餐 → 编辑」开启自定义
网段，Free 的其它额度无需改变。内置 Free 初始值仍为关闭；运营者可以按自己的
策略开启，这不是在 Core 按套餐名放行。当前调试站按用户要求开启后才可免费编辑。

## 升级与验证

组织注册表 v2 保存名称占用、v3 追加共享原生入口的精确键和控制面代际绑定；
Identity、State、Plans 版本不变。启动前导入已有有效名称并清理确认归档的历史占用。
先停止公共写入及旧实例并完整备份，再配套发布 Server 与 Web。原账户、密码、
会话、组织 ID、域名、Noise/TLS 密钥与设备地址不因迁移改写。
旧程序拒绝较新注册表；公开写入恢复后不能恢复旧数据库覆盖新状态。

验证源码：[名称及并发回归](../control/signup_login_test.go)、
[默认池及 Free 额度回归](../control/multiple_networks_test.go)。
客户端 wire 类型未改；开启 `self_service.native_gateway` 后设备与网页共用规范
HTTPS 入口，通过账户登录和独立设备审批确定归属，不需要租户泛证书。
未开启时浏览器共享控制台不意味着独立设备地址已经具备正确 DNS/TLS。
