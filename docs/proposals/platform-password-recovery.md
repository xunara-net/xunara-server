# Proposal：平台辅助的一次性密码重置

- 日期：2026-10-11
- 状态：Accepted，实施与验证中
- 范围：Server → Admin / Web → Docs / Deploy

## 问题与边界

忘记密码的用户目前只能依赖第三方 / Passkey 或数据库操作。联系邮箱未经验证，
不能直接充当恢复凭据，也不能让管理员查看旧密码。本切片交付人工核实后的平台
辅助恢复，不冒充自动邮件找回、完整账户接管恢复、MFA 或独立超管身份。

## 决策

1. Identity 仅追加 v17，一位用户至多持有一个待用重置凭证；随机 256-bit 码仅
   在生成响应中显示一次，数据库只存哈希，15 分钟到期。不放 URL、日志、argv、
   浏览器持久存储或审计；平台管理员通过已核实的独立渠道交付。
2. 仅平台 Bearer 可为已启用、已有本地密码且部署允许密码登录的账号生成重置码。
   必须确认已核实持有人、提供原因和用户完整版本，事务复核当前事实、替换旧码、更新版本及必需
   审计。普通 Cookie / 服务 API Key 不授予此能力。生成本身不改密码、不撤销
   会话，不因收到恢复请求锁住账号；取消确认不写入。
3. 匿名兑换仅接收 JSON POST 中的码、新密码和确认密码。不接收邮箱 / 用户 ID，
   不允许读取码对应的用户资料；无效、过期、已使用、禁用、跨租户及凭据变化
   返回相同拒绝。持久 IP 限流、严格体积 / 字段校验、no-store；不接受 query 码。
4. 慢哈希前验证凭证，之后在写事务内重新核对码、有效期、启用状态与原密码
   凭据版本，防止并发改密 / 轮换 / 禁用后凭旧结果恢复。密码替换、码删除、
   全部未撤销人类会话撤销、用户版本及必需审计原子提交，忽略写入亦失败回滚。
5. 更换密码使待用码失效并推进账号版本；禁用 / 解禁 / 删除账号在同事务删除待用码，解禁不能恢复旧码。
   重复生成使前一个码失效，兑换只成功一次；成功不自动登录，走原登录入口。
6. Admin 明示生成与兑换的不同效果、待用期限、原码不可找回；失败保留原因，
   结果未知先刷新核对，禁止自动重试。Web 登录页链接到无秘密参数的重置表单，
   双次密码确认，离开 / 成功清除输入，不写 sessionStorage / localStorage。
7. 保留 Human / Machine / Service 边界；不撤销外部绑定、Passkey、API Key、设备
   接入 Key、在线节点或中继身份，不改变套餐、官方客户端协议和既有注册准入。
   若疑似全面接管，仍需核实绑定、密钥和恢复渠道，不能仅靠改密宣称恢复安全。

## 验证与升级

覆盖真实旧库追加迁移、跨连接 / 重启持久化、重复生成 / 兑换竞争、过期、跨租户、
停用、旧凭据变化、慢哈希后的复核、CAS、密码 / 会话 / 码 / 审计写失败和忽略回滚。
Go build/vet/test/race；前端契约测试、构建、真实隔离 HTTPS、手机取消 / 冲突 /
兑换 / 新旧密码 / 重启验收。上线前停止全部旧控制面、成套私有备份，新库不混用
旧实例，公网只读 / 预览验证，不能擅自重置原用户密码。

## 依据

- Xunara 身份安全与账户恢复规格，以及现有密码 / 会话 / 账号禁用事务。
- [OWASP Forgot Password](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)：
  随机、受限、单次凭证；正常登录；匿名请求不能提前锁号，未验证属性不构成身份。
- [OWASP Authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)：
  恢复是高风险流程，不能把身份提供方属性或新渠道当作已核实的恢复证据。
