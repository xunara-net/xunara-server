# Proposal：设备连接详情与核心网络优先

日期：2026-10-12。状态：接受，见 [ADR-0035](../adr/ADR-0035-device-connection-details.md)。
范围：租户设备只读管理 API、设备详情及核心导航；不改变官方协议或身份模型。

## 问题与参考

设备详情目前只有基本信息与路由，无法回答设备的中继归属、客户端网络检测、
候选端点和中继探测延迟。用户要求先完善网络核心，而不是继续扩展外围账户功能。
参考 [Headplane](https://headplane.net/) 的设备/网络集中管理，不复制它的单实例
Session、配置直写或全局 Headscale 权限。官方字段以本仓库固定依赖
Tailscale v1.104.0 的 `tailcfg.NetInfo`、`DERPNode`、magicsock 与 netcheck 为准。

## 决策与数据流

1. 新增 `GET /api/v1/machines/{ref}/connection`，复用租户路由、既有 read scope
   与设备 ID 解析。读取本租户已持久化 Node/NetInfo 和已下发 DERP 地图，响应
   no-store；不新增表、迁移、套餐额度或机器命令。
2. 白名单输出控制面在线/最后联系、HomeDERP 与当前地图名称/来源/服务器端口、
   客户端首选区域、UDP/IPv6/NAT/端口映射检测、候选端点和中继探测延迟。
   原始 Hostinfo、日志/推送标识、Machine/Node/Disco Key 与凭据不得序列化。
3. HomeDERP 是中继归属，不是与任意 peer 的实时流量路径；NetInfo 是缓存报告，
   当前没有独立报告时间，不能用最后联系或本次读取时间冒充检测时间。未知 bool
   与 false 区分。DERPLatency 原值为秒，展示转换为毫秒，不冒充点对点 RTT。
4. 名称/服务器仅来自当前租户实际下发地图；过滤未下发区域、坏测量和旧格式 key。
   中继地图及来源从同一不可变快照读取，端点/服务器/测量有输出上限，响应列表
   稳定排序，避免并发热更新、跨租户泄露或恶意客户端数据膨胀。
5. Web 详情将连接/中继、网络和实际路由状态集中展示，支持刷新/失败重试；失败
   不渲染成空的成功网络，设备快速切换不混入旧结果。手机优先，次要细节折叠。
6. 导航保留核心设备、网络、ACL、DNS、路由与中继入口；套餐/审计/账户等归入
   可展开管理组，不删除已实现功能或放宽权限，直接书签仍可访问。

## 验证与边界

增加 API 权限/租户边界、nil/空地图/未下发 home、nil 与 false、秒转毫秒、坏键/
负值/非有限数、白名单隐私、限额/不改变节点及热更新快照竞态测试；复核原生
MapRequest→持久 NetInfo→管理 API，保留上游 Noise/MapResponse 测试。
Web 类型/契约/导航单测，真实隔离浏览器覆盖 owner/member、设备切换/故障、
移动布局与核心菜单，不把夹具报告当作真实公网测速或生产用户登录。

不新增实时 peer 遥测、测速代理、远程命令、设备健康评分或假直连标签，不把
控制面在线等同 WireGuard 可达。无数据库、身份、套餐、Headscale Adapter 或
Tailscale wire 改动；实际部署与全部剩余功能分别记账。
