# Proposal：手动设备过期与预授权一键加入

状态：实施前提案。日期：2026-10-12。

## 决策

- 设备详情及列表提供手动过期，先读取设备身份/有效期摘要版本并确认。仅租户
  owner/admin；Session CSRF、持久角色/凭据复查、只改 expiry、必需审计/通知同事务。
  不删除设备/地址或释放设备额度，不撤销人类会话、其它设备和中继。
- 添加设备支持预授权 Auth Key（不是超管令牌/API Key），现有密钥或生成短期
  一次性密钥；签发、配额与审计同事务，创建接口不保留非原子业务副本。
- 核对官方 CLI 的 auth-key=file:，复制命令不嵌入真实秘密，通过隐藏输入写
  0600 临时文件。Linux 私有一键脚本可显式下载，须私有保存/执行，运行时关闭
  跟踪、密钥仅进文件/stdin，退出清理。手机不冒充已支持的 CLI 接入。
- 使用密钥加入/轮换在租户节点库同事务重新验证凭据、机器/节点身份、设备额度、
  持久节点、必需审计及密钥消费，避免一次性密钥并发复用/消耗失败及 Free 第11台。
  已发布迁移不改，新功能不改变官方 Register/Map/Noise 字段或签名/标签语义。

## 验证

权限/CSRF/租户、设备替换/到期冲突、审计和计数故障回滚、配额/一次性并发消费、
原地址/路由/归属保持、官方 Noise 注册及过期/重新认证。命令执行夹具验证文件权限、
argv/输出无秘密、失败清理；UI 真实 API、手机、一次显示和关闭清理、成员拒写。
全量 Go build/vet/test/race、Web 类型/测试/构建和共享浏览器回归；上线一致私有备份，
不以生产账户/设备试写，不改变原凭据或默认 Relay。
