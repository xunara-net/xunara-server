# Proposal：私有中继安装脚本与分层健康检测

日期：2026-10-12。状态：接受，见 [ADR-0036](../adr/ADR-0036-private-relay-install-and-health.md)。依赖设备连接详情切片，均属于核心网络。

## 交付边界

- 我的设备增加添加设备向导：官方 Tailscale 安装器、按勾选生成 DNS/接收路由/
  子网/出口等参数。浏览器授权和设备审批保持独立，禁止 Auth Key 进入命令/URL。
- 私有中继提供 Linux systemd 安装脚本及预编译下载，自动选择 AMD64/ARM64/
  ARMv7 并校验固定发布版校验和；独立服务/目录，不覆盖部署默认公共中继。
  一次性接入令牌隐藏读取或从 root 私有文件读取，只进入私有环境文件；身份
  已存在时不重置或换控制面。可指定已核实的公有 CA，仅影响中继进程信任。
- 中继程序心跳健康增加本地实际 TLS/探测检查，不再仅根据监听地址对象判断。
  保持既有服务身份/心跳 wire 和官方 DERP/STUN 协议，不把本地 liveness 当公网健康。
- 私有中继列表增加主动检测：只探测本租户已登记中继，owner/admin、CSRF、
  持久速率限制与必需审计。地址/端口/pin 从登记读取，不接受任意 URL；只允许
  公网目标，DNS 解析后固定到已校验 IP，不用代理，不跟随重定向。
  TLS 采用官方 tlsdial 的 CA/CertName/sha256-raw 校验，固定 `/derp/probe` 与超时。
  结果明确为控制面视角 TCP/TLS/HTTP 探测，不替换心跳、准入、执行回执或真实数据面。

## 安全与兼容

无数据库迁移、套餐名称分支、Node/Human/Service 身份混用或新 Tailscale 字段。
探测是独立管理动作，不生成节点、不自动批准，也不改变中继配置/身份/健康存储。
阻止内网、loopback、link-local、CGNAT、混合 DNS 与重定向 SSRF；失败/审计故障
不得显示成功。平台令牌不在浏览器安装命令、URL、日志或下载产物里。

## 验证

安装命令参数/注入/额度测试，脚本校验、权限、身份保留与失败恢复的隔离测试；
真实 TLS/pin/重定向/坏证书/超时/SSRF 测试，Scope/CSRF/租户/限流/审计 API 测试；
中继本地探测与原数据面测试、全量 Go build/vet/test/race。Web 类型/单测/构建和
隔离手机浏览器验证，不在原站安装/重置默认中继或真实用户身份。
Windows/macOS 程序下载保留，Linux systemd 脚本不冒充全 OS 一键服务安装。
