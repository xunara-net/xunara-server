# Proposal：本人账户安全资料导出

状态：已实施并通过本地验证，发布 / 调试上线另行验收。范围对应产品规范 §10、
§83 的账户信息导出，不代表全部网络导出。

## 问题与数据流

本人资料、第三方绑定、通行密钥名称、会话及成功登录历史已有持久存储与读取
入口，但没有可下载的个人备份。直接串联页面 API 会产生非一致快照，容易误带
CSRF / 凭据字段，也会把分页首屏误当成完整历史。

拟定数据流：Settings 折叠导出表单 → 当前 Human Session + CSRF → 持久限流 →
租户身份事务复核会话 / 启用用户 → 有界白名单快照 + 必需准备审计 → 内存完整
编码 / 大小检查 → 私有 attachment → 浏览器显式下载与 Blob URL 清理。

## 决策

1. 新增 POST `/api/v1/account/export`；JSON 导出本人账户安全资料，CSV 仅导出
   本人成功登录记录。不接受目标用户 / 租户、URL、文件路径或任意 SQL 字段。
2. Free / 普通成员均可使用；平台 Bearer、机器或服务身份没有本人导出权限。
   HTTP 验证后仍在同一事务内条件锁定有效会话 / 启用用户，不信任旧快照。
3. 不新增或修改迁移。读取来自同一身份事务，采用明确允许字段，不导出密码、
   token / hash、CSRF、外部 subject、外部 token、Passkey credential / public key、
   OAuth 配置 secret、其他人的记录或网络管理员原因。
4. 成功登录历史支持创建时间半开区间 `[from, until)`；资料 / 活动会话 / 绑定
   不受该时间筛选。每个集合最多 5000 条，文件最多 8 MiB；超限整份拒绝，
   不悄悄截断，不把超限声明为无记录。应缩小历史区间后显式重试。
5. 事务提交必需 `account.export_prepared` 审计后才能返回；失败 / 忽略写入
   全部拒绝。只记范围 / 数量，不记录私人内容。它表示快照准备，不声称用户
   已保存文件；后续编码 / 网络失败不伪造下载成功。HTTP 持久限流失败关闭，
   共用 SQLite 配额写入必须确实影响一行，不能被忽略写入旁路。
6. 文件使用固定生成名称、no-store / nosniff / attachment，编码完成前不发
   文件头 / 部分数据，不生成临时公开 URL 或服务端导出缓存。
7. CSV 使用标准编码器处理分隔符 / 引号，UTF-8 BOM 便于中文查看；可能作为
   公式的文本加可见「文本：」前缀，JSON 保持原值。不宣称所有表格软件 / 再保存
   / 用户删前缀都安全，也不把 CSV 当凭据备份或机器无损导入格式。
8. UI 只在本人设置提供折叠入口、日期 / 格式与隐私确认，等待 / 失败不生成
   文件，不自动重试；离页取消，Blob 不入 localStorage / sessionStorage。

## 兼容与边界

现有 API / 生命周期 / 套餐不变，identity v18、state v24、plans v4 保持；不改
Tailscale / Headscale wire，不授予机器信任，不新增平台代导出权限。
没有失败登录、保留期自动删除、完整个人数据 / 租户网络导出、邮件、2FA、注销
或支付；快照不承诺网络配置与其他库的全局一致性。

## 验证

真实 SQLite 覆盖本人 / 跨用户 / 跨租户、撤销 / 禁用复核、同事务与跨连接，
限额 / 时间边界、取消、读故障与必需审计错误 / 忽略写入。HTTP 测试 CSRF、
JSON / query / 文件头、大小 / 限流、脱敏、CSV 公式 / 引号 / 换行。
Go build / vet / 全量 test / race，Web 类型 / 单测 / 构建，手机浏览器真实下载、
取消、错误、重启与现有登录历史回归；原站实测仅只读，不导出原用户私人资料。
